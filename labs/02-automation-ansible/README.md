# Lab 02 — Automation (Ansible)

**Objective:** write an idempotent Ansible playbook — configuration
management fundamentals, roles, and idempotence.

**Timebox:** ~45 min. If you're past 90, stop and ask in the course
discussion instead of pushing through alone.

**Where the work happens:** Red Hat Academy **RH294** — *Red Hat
Enterprise Linux Automation with Ansible* (v9.0), on rha.ole.redhat.com.
Your instructor gives you access; you complete the guided lab there.

**Grading:** entirely from your RHA RH294 lab completion. Your instructor
assigns your grade from the RHA portal — there's nothing to submit in this
repo for this lab.

**FOSS equivalent:** Ansible itself is already fully open-source — nothing
to swap there. The only RH-specific part of RH294 is the *infrastructure*
the guided labs run against (RHA's hosted cloud VMs); the playbooks you
write work identically against any target (a Vagrant VM, a container,
your own server).
